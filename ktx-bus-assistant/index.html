FAQ

미리 알아두면 좋은 점

지금 실제 취소표를 잡아주나요?

아니요. GitHub Pages는 공개 화면 데모이고, 별도 독립 앱은 이메일 계정과 조건 CRUD만 제공합니다. 실제 모니터링·좌석 선점·알림톡에는 운영사 공식 연동이 필요합니다.

코레일 열차도 자동으로 예약할 수 있나요?

아직은 불가능합니다. 참고한 railway-timetable 스킬은 코레일의 계획 시간표 조회만 제공하며 실시간 잔여석, 자동 재조회, 예약·좌석 확보는 지원하지 않습니다. 현재 화면도 이 제한을 그대로 표시합니다.

좌석이 확보되면 예매가 끝난 건가요?

아닙니다. 버스 좌석의 임시 확보는 결제 전 단계이며 짧게 해제될 수 있습니다. 공식 결제 페이지에서 사용자가 직접 결제를 마쳐야 예매가 확정됩니다.

왜 “10분 안에 결제”라고 표시하지 않나요?

공식 응답에서 정확한 만료 시각이 확인되지 않으면 임의의 카운트다운을 보여주지 않습니다. 실제 연동에서는 공급자가 반환한 만료 시각이 있을 때만 남은 시간을 표시합니다.
