# 자리ON — 기차·버스 예매 도우미

자리ON은 매진된 코레일 열차·고속버스·시외버스의 취소표 모니터링을 목표로 하는 웹앱입니다. 현재 배포는 공개 소개 데모와 소유자 전용 풀스택 베타로 나뉩니다.

## 배포 구성

### GitHub Pages — 공개 소개·화면 데모

- 주소: <https://ookk2007.github.io/ktx-bus-assistant/>
- KTX 예시 시간표와 고속·시외버스 예시 데이터를 사용합니다.
- 검색, 조건 저장, 일시 중지, 삭제, 빈자리 알림 상황을 브라우저에서 체험합니다.
- 조건은 이 브라우저의 `localStorage`에만 저장되며 개인정보를 받지 않습니다.
- 실제 운송사 요청, 실시간 잔여석 조회, 좌석 확보, 예매, 알림톡 발송은 실행하지 않습니다.

### 자리ON 서비스 앱 — 소유자 전용 베타

- 주소: <https://jarion-booking-assistant.ookk2007.chatgpt.site>
- ChatGPT Sites 로그인을 사용합니다.
- D1에 사용자별 프로필, 알림 연락처, 모니터링 조건과 상태 이력을 분리해 저장합니다.
- 조건 추가, 목록 조회, 일시 중지·재개, 삭제를 지원합니다.
- 종료 시각이 지난 조건은 사용자가 목록을 열거나 작업을 실행할 때 정리합니다. 아직 백그라운드 예약 작업은 아닙니다.
- 사용자당 최대 20개 조건과 동일 조건 중복 방지를 적용합니다.

## 지원하는 조건 범위

- 코레일: KTX, KTX-산천, ITX-새마을, ITX-마음, 새마을호, 무궁화호, 누리로, ITX-청춘, S-Train 등 관광열차
- 고속버스: KOBUS 노선 후보
- 시외버스: 티머니 시외버스 노선 후보
- 출발지와 도착지는 추천 목록에서 선택하거나 직접 입력할 수 있습니다.

현재의 역·터미널 목록은 화면 입력을 돕는 추천 목록입니다. 실제 연동 전에는 운영사 공식 코드 카탈로그와 동기화하고 서버에서 코드 유효성을 검증해야 합니다.

## 계정과 개인정보 원칙

- 별도의 자리ON 비밀번호를 만들지 않고 Sites 인증을 사용합니다.
- 코레일·KOBUS·티머니GO ID/PW, 결제 카드, 운송사 세션을 저장하지 않습니다.
- 카카오 알림톡은 카카오톡 ID가 아니라 법적으로 수집된 휴대전화번호와 승인된 메시지 템플릿이 필요합니다.
- 베타 앱에 저장한 알림 연락처는 설정 화면에서 지울 수 있습니다.
- 현재 서비스 앱은 소유자 전용입니다. 공개 전에는 개인정보 암호화, 보유·파기 정책, 계정 삭제, 감사 로그를 추가해야 합니다.

## 아직 제공하지 않는 기능

- 실시간 잔여석 폴링과 백그라운드 작업 큐
- 코레일·KOBUS·티머니GO 좌석 확보 또는 자동 예매
- 카카오 알림톡 실발송
- 결제 세션 생성과 결제 자동화

이 기능들은 공개 웹 화면만으로 안전하게 구현할 수 없습니다. 운영사의 공식 제휴/B2B API, 호출 정책, 오류·차단 처리, 만료 시각 검증, 카카오 비즈메시지 계약이 준비된 뒤 서버 어댑터와 작업 큐로 연결해야 합니다. CAPTCHA 우회, 공격적 폴링, 비공개 엔드포인트 의존, 평문 비밀번호 저장은 하지 않습니다.

## 티머니GO 조사 결과

티머니GO 소비자 앱은 고속버스와 시외버스 조회·예매를 통합하지만, 공개된 소비자 로그인·예매 API는 확인되지 않았습니다. 외부 서비스에서 계정을 대신 사용하기보다 티머니의 제휴/B2B 절차를 통해 공식 접근 권한을 받아야 합니다.
